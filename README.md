# Simple Chess Game

This is a small browser-based chess game project.

## Files

- `start.html` — the main web page for the game.
- `me.js` — game logic, board rendering, controls, and bot mode.
- `point.css` — page styling.
- `my.py` — an unrelated Python file in this folder.

## How to run

1. Open `start.html` in a web browser.
2. The board will appear and the game starts automatically.
3. Use the buttons to switch between "Play vs Bot", "Play with Friend", or restart the game.

## Notes

- `start.html` must load `me.js` for the game to work.
- If the page does not load, check the browser console for missing file or script errors.
